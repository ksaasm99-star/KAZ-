# KAZ - مصنع التطبيقات الذكي (Smart AI App Factory)

تطبيق أندرويد متطور وذكي لبناء وتوليد تطبيقات أندرويد متكاملة بنسبة 100% باستخدام الذكاء الاصطناعي التوليدي عبر **Gemini API**.

## 🌟 الميزات الرئيسية (Core Features)

1. **الشاشة الرئيسية (Projects Dashboard)**:
   - استعراض وإدارة جميع المشاريع وتطبيقات الأندرويد المحفوظة محليًا.
   - زر بارز لإنشاء وبدء "مشروع جديد".
   - بحث فوري في المشاريع السابقة.
   - مخصص لمستخدم واحد فقط (المالك) بدون الحاجة لأي تسجيل دخول ودون قيود.

2. **شاشة البناء الذكي (Build Screen)**:
   - خانة تفاعلية لكتابة وصف التطبيق بالعربي بكل حرية.
   - اقتراحات سريعة لأفكار التطبيقات (متجر إلكتروني، توصيل طلبات، إدارة مهام، محفظة رقمية، حجز عيادات، منصة تدوين).
   - مؤشر مراحل البناء المباشر بواسطة Gemini AI.

3. **شاشة النتيجة ومستعرض الأكواد (Result Screen)**:
   - عرض الكود البرمجي الكامل في صندوق قابل للتمرير مع أرقام الأسطر والتلوين البرمجي المتقدم.
   - تبويبات للملفات البرمجية (`Screen.kt`, `ViewModel.kt`, `Model.kt`).
   - زر نسخ الكود بضغطة زر واحدة إلى الحافظة.
   - محاكي معاينة حية تفاعلية (Interactive Live Preview).

4. **المساعد الذكي (KAZ AI Chat)**:
   - إمكانية مواصلة المحادثة لتعديل التطبيق وإضافة ميزات جديدة.
   - استخراج وتنسيق كتل الأكواد تلقائيًا.

5. **شاشة الإعدادات والوضع الليلي (Settings)**:
   - دعم الوضع الليلي (Dark Mode) الفاخر والوضع النهاري (Light Mode) والتلقائي.
   - فحص وتخصيص مفتاح Gemini API.
   - دعم كامل للغة العربية والإنجليزية.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **لغة البرمجة**: Kotlin 2.1
- **واجهة المستخدم**: Jetpack Compose + Material Design 3
- **قاعدة البيانات المحلية**: Room Database (Entity, DAO, Repository)
- **الشبكة والذكاء الاصطناعي**: Retrofit + OkHttp + Kotlinx Serialization + Google Gemini API
- **الهندسة البرمجية**: Clean Architecture + Modular MVVM
- **التصميم المتجاوب**: دعم كامل لتوجيه النصوص العربية (RTL) والحواف الشاملة (Edge-to-Edge)
