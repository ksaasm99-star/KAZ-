# KAZ Web App

هذا المجلد هو واجهة الويب الرسمية لمشروع KAZ داخل نفس المستودع.

## الحالة الحالية

المرحلة الحالية هي **أساس المشروع فقط**. تم تجهيز React + TypeScript + Vite مع دعم العربية واتجاه RTL وملف المسارات. لم تُبنَ شاشة أو وظيفة منتج بعد.

## التشغيل

```bash
pnpm install
pnpm run check
pnpm run build
pnpm run dev
```

## قواعد النطاق

- تطبيق Android الموجود في جذر المستودع لا يُعدّل من هذا المجلد.
- كل شاشة تُبنى وتُتحقق منها في دورة مستقلة.
- لا تُضاف بيانات وهمية أو أزرار شكلية بدل الوظائف الحقيقية.
- لا تُحفظ الأسرار في ملفات الواجهة أو Git.
